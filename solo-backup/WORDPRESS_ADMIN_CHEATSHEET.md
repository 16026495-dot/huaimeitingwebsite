# ⭐ 最常用的10个操作 (90%的时间只用这些!)

## 1️⃣ 发布新产品/文章

```
路径: 文章 → 新建文章

步骤:
1. 标题: "医用弹力面罩 - 术后面部加压固定"
2. 内容: 写产品介绍、特点、价格等
3. 特色图片: 右侧 "设置特色图片" → 上传图片
4. 分类: 选择 "医美术后修复" 或其他分类
5. 标签: "NMPA认证", "透气舒适"
6. 点击蓝色 "发布" 按钮

✅ 完成! 产品已上线!
```

## 2️⃣ 修改文字内容

```
路径: 页面 → 所有页面 → 找到要改的页面 → 点击 "编辑"

修改方法:
- 直接在编辑框里打字 (像Word一样!)
- 使用工具栏加粗/斜体/列表
- 点击 "更新" 保存

✅ 改完立即生效! 刷新前台就能看到!
```

## 3️⃣ 更换图片

```
方法A: 替换现有图片
1. 在编辑器中点击旧图片
2. 点击 "替换" 图标
3. 上传新图片
4. 更新页面

方法B: 上传新图片到媒体库
1. 媒体 → 添加新媒体
2. 选择文件上传
3. 复制图片链接
4. 在页面中粘贴链接
```

## 4️⃣ 修改联系方式 (电话/微信/邮箱)

```
方法A: 如果用了小工具
外观 → 小工具 → 找到"联系信息"小工具 → 修改 → 保存

方法B: 如果写在页面里
页面 → 编辑对应页面 → 修改文字 → 更新

方法C: 全局修改 (需要技术人员帮忙)
functions.php → huaimeiting_contact_info() 函数
```

## 5️⃣ 修改网站Logo

```
外观 → 自定义 → 网站标识 Site Identity
→ 点击 "选择Logo"
→ 上传Logo图片 (建议PNG透明底, 高度80-100px)
→ 点击 "裁剪并发布"
→ 右上角 "发布" 按钮

✅ Logo已更换!
```

## 6️⃣ 修改导航菜单

```
外观 → 菜单 → 选择菜单 (或创建新菜单)

添加菜单项:
1. 左侧 "添加菜单项" 
2. 选择类型:
   - 自定义链接 (输入URL和文字)
   - 页面 (选择已有页面)
   - 分类 (文章分类)
3. 点击 "添加到菜单"
4. 拖拽调整顺序
5. 底部 "保存菜单"

✅ 菜单已更新!
```

## 7️⃣ 回复客户评论

```
评论 → 待审/已批准

操作:
- 通过 (Approve): 显示在前台
- 回复 (Reply): 回复客户
- 垃圾 (Spam): 删除垃圾信息
- 编辑 (Edit): 修改评论内容
```

## 8️⃣ 安装新插件

```
插件 → 添加新插件

搜索推荐:
- Elementor (页面构建器)
- Contact Form 7 (联系表单)
- Yoast SEO (搜索引擎优化)
- Smush (图片压缩)
- UpdraftPlus (自动备份)

安装步骤:
1. 搜索插件名称
2. 点击 "现在安装"
3. 点击 "激活"
✅ 插件可用!
```

## 9️⃣ 查看访问统计

```
仪表盘 Dashboard → "概览" 模块

显示:
- 今日访客数
- 今日文章浏览量
- 最新搜索词
- 最新评论
- WordPress新闻

💡 安装更多统计:
插件 → 搜索 "Google Analytics" 或 "MonsterInsights"
安装后可以看到更详细的访问数据!
```

## 🔟 备份网站

### 手动备份:
```
工具 → 导出 → 选择 "全部内容" → 下载文件
保存到电脑或云盘 (Google Drive/Dropbox)
```

### 自动备份 (推荐):
```
1. 安装 UpdraftPlus 插件
2. 设置 → UpdraftPlus Backups
3. 设置备份计划:
   - 备份频率: 每周
   - 保留份数: 4份
   - 云存储: Google Drive/Dropbox
4. 保存设置

✅ 从此每周自动备份,无需操心!
```

# 🚨 常见问题快速解决

## 问题1: 白屏/错误页面

```
原因: 插件冲突或代码错误

解决:
1. 重命名 plugins 文件夹为 plugins.old (通过FTP)
2. 刷新网站,如果恢复 = 插件问题
3. 把文件夹名改回 plugins
4. 逐个禁用插件找出问题插件
```

## 问题2: 登录不了

```
解决:
1. 清除浏览器缓存 (Ctrl+Shift+Delete)
2. 尝试无痕模式
3. 重置密码 (登录页 → 忘记密码?)
4. 检查用户名是否正确 (注意大小写!)
```

## 问题3: 图片上传失败

```
原因: 图片太大 (>2MB) 或权限问题

解决:
1. 压缩图片到 <500KB
2. 设置 → 媒体 → 增加上传限制
3. 安装 Smush 插件自动压缩
4. 检查 wp-content/uploads 权限 (755)
```

## 问题4: 修改了但看不到变化

```
解决:
1. 强制刷新: Ctrl+F5 (Windows) / Cmd+Shift+R (Mac)
2. 清除缓存: 浏览器清除缓存
3. 检查是否点了 "更新/发布" 按钮
4. 查看是否在正确的页面/文章上
```

## 问题5: 菜单不显示

```
解决:
1. 外观 → 菜单 → 确认菜单已创建
2. 检查菜单位置是否分配正确
3. 主题是否支持该菜单位置
4. 清除缓存再试
```

# 💡 专业技巧 Tips & Tricks

## Tip 1: 快捷键
```
Ctrl+S = 保存草稿 (不是发布!)
Ctrl+Z = 撤销
Ctrl+B = 加粗
Ctrl+I = 斜体
Ctrl+K = 插入链接
Alt+Shift+X = HTML模式切换
```

## Tip 2: 草稿箱
```
写了一半的文章想保存?
右上角 "保存为草稿"
下次从 "文章 → 草稿" 继续
```

## Tip 3: 预览功能
```
不确定发布后的样子?
点击 "预览" 按钮
在新标签页查看效果
满意后再点 "发布"
```

## Tip 4: 版本历史
```
不小心删错了内容?
页面/文章右侧 "版本" 面板
点击任意版本可恢复到那个状态
```

## Tip 5: 屏幕选项
```
编辑页面顶部 "屏幕选项" 按钮
可以隐藏不需要的模块
让界面更简洁!
```
