# 🚀 第3章：FileZilla上传教程 (详细图文版)

## 📥 下载FileZilla (如果还没装)

**下载地址:** https://filezilla-project.org/

选择 **FileZilla Client** 下载安装

---

## 🔗 连接到服务器 (跟着做!)

### 第1步: 打开FileZilla

双击桌面上的 FileZilla 图标

### 第2步: 填写连接信息

在顶部栏看到4个框框:

```
┌─────────────────────────────────────────────────────┐
│ 文件(F)  编辑(E)  视图(V)  传输(T)  服务器(S)  帮助(H) │
├─────────────────────────────────────────────────────┤
│ 主机: [ftp.yourhost.com        ]  用户名: [admin    ] │
│ 密码: [••••••••                ]  端口:   [21       ] │
├─────────────────────────────────────────────────────┤
│                                                     │
│  本地站点                          远程站点          │
│  ┌─────────┐                     ┌─────────┐        │
│  │         │                     │         │        │
│  │ 你的电脑 │                     │ 服务器   │        │
│  │         │                     │         │        │
│  └─────────┘                     └─────────┘        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**填写方法:**
- **主机**: 你的FTP地址 (从主机商获取)
- **用户名**: FTP用户名
- **密码**: FTP密码
- **端口**: 21 (默认不用改)

### 第3步: 点击"快速连接"

点击右下角的 **"快速连接"** 按钮

### 第4步: 等待连接成功

看到右侧显示文件列表 = 连接成功! ✅

如果失败,检查:
- 用户名密码是否正确?
- 端口是不是21?
- 防火墙是否阻止?

# 🌐 第5章：绑定域名 www.huameiting.cn

## 🔗 方法1: DNS设置 (推荐)

### 登录域名管理面板

去你购买域名的地方 (阿里云/腾讯云/Godaddy等)

### 找到DNS管理

找到 **"DNS解析"** 或 **"Domain Nameservers"**

### 添加记录

添加这两条记录:

```
类型: A 记录
主机: @
值: 你的服务器IP地址 (从主机商获取)
TTL: 600

类型: CNAME 记录
主机: www
值: huameiting.cn
TTL: 600
```

### 等待生效 (10分钟-24小时)

**测试:** 在浏览器输入 `www.huameiting.cn` 能打开网站 = 成功!

---

## 🔗 方法2: 在WordPress中设置

### WordPress后台 → 设置 → 常规

修改这两个地址:
```
WordPress地址(URL): https://www.huameiting.cn
网站地址(URL): https://www.huameiting.cn
```

点击 **"保存更改"**

# ❓ 第7章：常见问题解答

## Q1: 忘记WordPress密码怎么办?

**解决方法:**
```
登录页面点击 "忘记密码?"
→ 输入你的邮箱
→ 收到重置邮件
→ 设置新密码
```

## Q2: 网站打不开/白屏?

**可能原因:**
- 插件冲突 → 禁用最近安装的插件
- 主题错误 → 切换回默认主题
- 内存不足 → 联系主机商升级

**快速修复:**
```
访问: www.huameiting.cn/wp-login.php
如果能登录 → 问题不大,禁用插件试试
如果无法登录 → 联系主机客服!
```

## Q3: 图片上传失败?

**原因:** 图片太大!

**解决:**
- 压缩图片到 < 2MB
- 或者安装插件 "Smush" 自动压缩
- 或者在 媒体设置 中增加上传限制

## Q4: 想修改网站颜色/字体?

**使用Elementor:**
```
编辑页面 → Elementor → 右键元素 → 编辑样式 → 改颜色/字体
```

**或者:**
```
外观 → 自定义 → 颜色/字体 → 修改 → 发布
```

## Q5: 如何添加微信二维码?

**步骤:**
1. **媒体** → **上传微信二维码图片**
2. **复制图片链接**
3. **页面** → **编辑** → **添加"图像"块** → **粘贴链接**
4. **保存**

## Q6: 手机上看起来不一样?

**确保:**
- 使用响应式主题 (我们的主题已经是了!)
- Elementor编辑器底部有手机预览按钮
- 在不同设备上测试一下

## Q7: 备份怎么做?

**安装备份插件:**
```
插件 → 安装插件 → 搜索 "UpdraftPlus" → 安装 → 激活
→ 设置 → 立即备份
→ 设置自动每周备份
```

**手动备份:**
```
工具 → 导出 → 下载全部内容 (XML文件) + FileZilla下载所有文件
```

## Q8: SEO优化? 让百度/谷歌搜到?

**安装SEO插件:**
```
插件 → 安装 "Yoast SEO" 或 "Rank Math"
```
