⏱️ 预计完成时间： 10分钟 | 难度等级： ⭐ 简单 | 费用： 完全免费

启用 GitHub Pages（2分钟）

  1. 点击这里打开 GitHub 设置： 📍 打开仓库设置页面
  2. 在左侧菜单找到并点击 Pages
  3. 在 "Source" 下拉菜单中选择："Deploy from a branch"
  4. 在 "Branch" 下拉菜单选择：main，Folder 选择：/ (root)
  5. 点击绿色按钮 "Save"
  6. 等待 1-2 分钟，您会看到提示："Your site is ready to be published at..."
  7. 访问测试链接确认网站正常： 🔗 预览网站

在 WordPress 中创建页面（3分钟）

  1. 打开浏览器访问：WordPress 后台
  2. 使用您的 WordPress.com 账户登录
  3. 左侧菜单点击 页面 (Pages)
  4. 点击 新建页面 (Add New)
  5. 页面标题输入："首页" 或 "怀美婷医疗"
  6. 点击 "+" 号添加新块
  7. 搜索并选择 自定义 HTML (Custom HTML)
  8. 粘贴上面复制的代码（Ctrl+V 或 Cmd+V）
  9. 点击右上角蓝色的 "发布 (Publish)" 按钮

设置为首页（1分钟）

  1. 左侧菜单：设置 (Settings) → 阅读 (Reading)
  2. 在 "首页显示" 部分选择："一个静态页面 (A static page)"
  3. 在 "首页 (Homepage)" 下拉菜单中选择刚创建的 "首页"
  4. 点击 "保存更改 (Save Changes)"

最终测试（2分钟）

  1. 访问您的 WordPress 网站： 🌐 查看我的网站
  2. 确认怀美婷医疗网站正常显示
  3. 测试产品卡片点击功能
  4. 在手机上打开测试移动端显示
  5. 如果显示正常，恭喜！部署成功！🎉
